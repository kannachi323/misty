# Misty iPhone 6.5-Inch App Store Screenshots

This folder contains optional 1242 x 2688 screenshots for the 6.5-inch iPhone display class.

Use `designed-fallback/` only if App Store Connect asks for a 6.5-inch set in addition to the primary 6.9-inch screenshots. The primary submission-safe set remains `../../iphone-6-9/en-US/designed-fallback/`.

`fallback-direct-resize/` contains plain resized simulator captures and is kept as a compatibility fallback.
