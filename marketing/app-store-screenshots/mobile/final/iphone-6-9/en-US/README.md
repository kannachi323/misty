# Misty iPhone App Store Screenshots

Use `designed-fallback/` as the current submission-safe screenshot set.

The optional 6.5-inch companion set is at `../../iphone-6-5/en-US/designed-fallback/`.

`fallback-direct-resize/` contains plain resized simulator captures and is kept as a compatibility fallback.

`butterkit-watermarked-draft/` is not submission-safe because the direct ButterKit export adds a visible watermark and was generated before final UI approval. Do not upload it to App Store Connect. Only resume screenshot production after the mobile UI is approved, and only upload no-watermark assets.
