MISTY — V1.0 SHIP LIST
======================

SHIP BLOCKERS
-------------
[ ] Graceful shutdown
    - Drain or cancel in-flight worker tasks before app teardown.
    - Make proxy auth/config listeners and background jobs stop cleanly on exit.

[ ] Offline / proxy-down UX
    - Replace raw network/proxy errors with a clean offline state.
    - Add obvious retry actions for Services, Vault, and remote-backed file views.

[ ] Remote auth/config hardening
    - Stress-test repeated cancel/retry flows for OAuth providers.
    - Keep filtering low-level rclone prompts so users only see choices that help them.
    - Make failed or abandoned config flows recover without requiring a proxy restart.

[ ] Release packaging / first-run validation
    - Verify the production app bundle includes proxy, restic, misty-pwd-helper, assets, and icons.
    - Add a startup sanity check for missing bundled binaries and show a user-friendly error if anything is missing.

[ ] Production QA pass on a clean macOS user environment
    - Test: sign in, connect providers, browse local + remote, upload/download, search, rename service alias, delete/trash/permanent delete, Vault backup, Vault restore, quit/relaunch.
    - Run this without relying on dev-only paths or already-installed binaries.

SHOULD HAVE BEFORE OR IMMEDIATELY AFTER 1.0
-------------------------------------------
[ ] Provider-specific setup polish
    - Normalize common provider flows instead of mirroring raw backend wording.
    - Keep advanced or unusual options out of the primary happy path.

[ ] Log capture / support export
    - Provide one easy way to collect app + proxy logs for production debugging.

[ ] Bundle restic for Windows/Linux too
    - macOS is covered first. Mirror the packaging and binary lookup flow for Windows and Linux release artifacts.

DEFERRED
--------
[ ] Drag and drop
[ ] Customizable UI
[ ] iCloud upload support
[ ] iCloud 2FA flow hardening
[ ] In-app scheduler (cron-style backup plans)
[ ] Email / webhook notifications on job completion
[ ] restic copy-based replication between repos
[ ] Find/search across snapshots (restic find)
