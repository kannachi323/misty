Detailed Description

Manages the claude CLI as a subprocess.

Each call to send_message() spawns: claude -p "<prompt>" –output-format stream-json –verbose [–resume <session_id>]

Output is read line-by-line on a background thread and parsed into ClaudeEvents that the UI drains every frame.
