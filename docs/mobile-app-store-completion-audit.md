## Current Blockers

- Final no-watermark App Store screenshots should be regenerated only after the mobile UI is approved; the current Butterkit draft exports include a watermark and must not be uploaded.
- Xcode/App Store Connect signing credentials and provisioning for `com.misty.mobile` are required for TestFlight/App Store export/upload.
- Production support URL and privacy policy URL must be supplied.
- Reviewer demo credentials must be supplied.
- Live provider OAuth/deep-link return and real-device/TestFlight smoke tests require external credentials/signing.
- Xcode's privacy report must be generated from the final signed archive and reconciled with App Store privacy labels.
