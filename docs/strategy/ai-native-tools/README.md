# Misty AI-Native Workstreams

This directory splits the [combined AI-native product plan](../ai-native-tool-plan.md) into one self-contained brief per Codex thread.

Each brief includes:

- a copyable thread objective;
- the current implementation assessment;
- the intended scope versus a full standalone product;
- the next implementation stages;
- the production bar;
- required thread outputs and a shared acceptance gate.

## Shared north star

> Misty turns the desktop from a collection of tools people operate alone into a shared environment where people and AI can see, create, manipulate, review, and hand off the same work together in real time.

## Recommended thread sequence

Do not launch every workstream as an independent implementation at once. The shared collaboration and trust contracts should land before dependent surface work.

## Suggested opening message for a thread

> Use the attached Misty workstream brief as the scope for this task. Inspect the current implementation first and correct any stale assumptions. Then produce a staged plan and implement the highest-leverage coherent slice that fits the brief. Preserve unrelated work, verify native desktop behavior where applicable, and finish with remaining gaps and the recommended next slice.

## Coordination rule

If a workstream needs to change the AI Surface contract, artifact protocol, context boundary, permission model, workspace routing, or shared Misty state machine, coordinate that change through the foundation workstream rather than inventing a surface-specific alternative.
