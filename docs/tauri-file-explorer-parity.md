# Tauri File Explorer Parity Ledger

This is a current-state migration ledger for the File Explorer refactor from the native ImGui/C++ implementation to the Tauri/Rust/React implementation.

It is intentionally evidence-based: every row references the source area that currently proves the native behavior and the Tauri status. "Partial" means the visible workflow exists but still lacks one or more native behaviors.

## Recent Tauri Improvements

- Explorer Inspector is now functional rather than decorative: it handles empty/single/multiple selection like native, dispatches Open and More actions, and renders bounded local image/PDF preview payloads without exposing unrestricted filesystem URLs to the webview.
- Directory list and grid density now comes directly from native measurements: 32px table rows with compact cell padding and 100×104 grid cells with 32px icons, while retaining Tauri virtualization and adjustable columns.
- Local symlinks now match native open semantics: backend directory inspection follows the target, directory links navigate in Explorer, file links open through the normal OS association path, and external drops classify linked directories correctly.
- Inline rename now follows native selection-driven focus: clicking, range-selecting, toggling, or clearing participants rebuilds the live rename set and moves the focused editor without an accidental blur commit.
- Narrow Transfers panes now preserve the native minimum-width Filters/Table/Detail canvas and own its horizontal overflow, so neither the app body nor the surrounding MultiPanel workspace shifts or clips the inspector.
- Inline create/rename now shows a native-style status banner with Create/Rename mode guidance plus ready/unchanged/invalid counts while the draft is active.
- Tauri Providers can now establish its own remote connections: protected proxy requests use the shared desktop access token with refresh/retry, and the Providers UI supports workflow selection, dynamic setup fields, browser authorization polling, reconnect/configure, and confirmed disconnect instead of depending on remotes created by ImGui.
- Shared React MultiPanel state is now factory-capable and `MultiPanelWorkspace` can render against a supplied store instance, unblocking Transfers/Providers from adopting MultiPanel without colliding with Explorer's singleton tab/pane IDs.
- Transfers now uses its own MultiPanel store, so transfer history tabs/splits can keep independent search, filters, pagination, selected rows, and focused detail while sharing the same transfer records and operation queue.
- Transfers now persists safe MultiPanel tab/split layout snapshots in localStorage, including active tab/pane IDs, closed panes, and split metadata without serializing transfer records, filters, selections, or secrets.
- Providers now uses its own MultiPanel store with persisted safe tab/split layout snapshots, while each provider pane keeps independent selected remote drafts, token visibility, config paths, and edit/test/save state over the shared rclone service model.
- Providers dirty remote drafts now guard MultiPanel pane/tab close actions; confirmed closure discards only the affected provider pane workspaces and never writes draft config values or tokens into restore snapshots.
- Providers panes now track per-remote mutation revisions, preserve local drafts when another pane renames/deletes/updates the selected remote, mark those drafts stale, and disable Save until the user reloads or reselects the remote.
- Explorer toolbar breadcrumbs now have the native-style editable path mode: activate the breadcrumb bar, type a local/virtual/remote path, press Enter to navigate, or Escape/blur to restore.
- Explorer split panes now keep the toolbar as a shared active-pane control while each pane shows a compact local path header; the tab strip also reserves fixed space for Add Tab and pane actions so tab overflow stays local.
- New File/New Folder actions now use the same pane capability check from the toolbar popup, context menu, and create command path, matching native disabled behavior in virtual folders like Recent, Starred, and Trash.
- MultiPanel pane close/restore now preserves the exact native lane and row placement, keeps closed panes scoped to their source top-level tab, and round-trips that metadata through native workspace snapshots instead of duplicating closed panes across tabs.
- Transfers now matches native 25-row filtered pagination, including page reset/clamping, Previous/Next controls, select/deselect-current-page behavior, and Cancel/Retry/Undo actions in the detail inspector.
- List view now virtualizes table rows in `FileBrowser.tsx`, reducing DOM churn for large directories.
- Grid view now virtualizes tile rows in `FileBrowser.tsx`, reducing DOM churn for large directories while preserving selection, drag/drop, and inline rename/create.
- Transfers now virtualizes filtered table rows in `TransfersWorkspace.tsx`, reducing DOM churn during polling, sorting, and provider/type/status filtering.
- File table scroll state is throttled to animation frames, reducing React churn while scrolling large directories.
- File list sort state now lives in `useExplorerStore.ts`, so sorted order is consistent for selection and workspace saves.
- Toolbar search now filters the visible directory entries by name, type, provider, and remote.
- File table columns can now be resized and their widths are persisted in localStorage.
- File table columns can now be drag-reordered and their order is persisted in localStorage.
- Explorer sorting is now pane-scoped and persisted per workspace pane, so split panes can keep independent Name/Modified/Size/Type ordering instead of sharing one global sort.
- Remote files can now be opened from Tauri by preparing a cached local copy and then delegating to the OS opener.
- The upload toolbar now supports folder selection and queues directory uploads through the existing folder-aware Rust upload path.
- Native OS file/folder drops into the Tauri Explorer now resolve the target pane/folder and enter the background operation queue as copy/upload work.
- Internal and native OS drags now use delayed folder hover navigation, matching the native 3s hover-open behavior.
- The Explorer search field now has a `>` command mode for native-equivalent core explorer commands on the active pane.
- `Cmd/Ctrl+P` now opens Explorer command mode, and command mode now includes executable MultiPanel tab/pane commands, tab selection, Open With, preview/sidebar toggles, and hidden-file toggling.
- Explorer command mode now includes app route commands for Transfers and Settings through React Router navigation.
- Explorer search now shows location suggestions for quick access folders, pinned paths, and connected remotes, and Enter/click navigates the active pane to the selected location.
- Explorer search now reads the native-compatible explorer library cache for Recent and Starred suggestions, records opened entries and last-opened paths back to that cache, and includes active workspace pane roots as Workspace suggestions.
- Explorer sidebar can now navigate native-compatible `misty://recent` and `misty://starred` virtual listings, with tab titles and breadcrumbs matching those virtual locations.
- Explorer sidebar can now navigate native-compatible `misty://trash` virtual listings from the local Misty trash cache, with tab titles and breadcrumbs matching that virtual location.
- Trash virtual listing entries now carry an explicit deleted marker, render with a deleted/trash affordance, and are excluded from normal FileMaster actions to match native `FileType::DELETED` behavior.
- Operation queue snapshots/actions are now exposed through Tauri commands and visible in Transfers, including conflict resolution controls.
- Explorer paste/drop/upload now enqueue through `OperationQueueService` and pump onto background Explorer operations instead of blocking the UI on direct paste calls.
- Explorer create, rename, and confirmed delete now use the same background operation queue; multi-item deletes are split into independently retryable operations.
- Queued local paste conflicts now pause for resolution, preserve the operation payload while waiting, prune terminal payloads, and safely execute Replace/Skip policies.
- Queued local paste Keep Both now creates available sibling names such as `report copy.txt` and `report copy 2.txt`.
- Queued remote upload/download/copy/move now preflight destination conflicts through parent listings and honor conflict-generated target names end to end.
- Failed operation payloads now survive unrelated cancel/conflict actions so queue Retry remains executable until terminal history is cleared.
- In-progress operation cancellation now marks queue items canceled, unpauses conflict-blocked batches, signals running queue workers between supported steps, and prevents late worker completion from overwriting canceled state.
- New file/folder and single-item rename now use focused inline editors in list and grid views; file extensions remain locked, invalid/duplicate names stay editable with feedback, Enter commits, and Escape cancels.
- Multi-selection rename now opens a review dialog, validates all proposed names, preserves file extensions, and queues one background rename operation per changed item.
- Multi-selection rename now gathers selected items across loaded panes, validates collisions per source folder, and refreshes only the panes touched by the confirmed rename.
- Multi-selection inline rename now propagates the focused draft to every selected participant before opening the review dialog, matching native shared-draft rename behavior more closely.
- Inline rename/create now selects only the editable name portion when the session starts, keeps the caret stable during validation updates, ignores composing Enter/Escape key events, and focuses the first invalid batch-review row.
- Explorer now observes completed transfer history changes and refreshes only panes whose current directory was touched by the transfer, matching native transfer-listener relist behavior.
- Explorer now supports Open With for selected files, remembers the chosen application by extension/name in settings, and uses that mapping for later opens.
- Explorer table inline-edit styling no longer relies on a broad `:has()` selector in the scroll hot path.
- Open With association lookup now lives in the Tauri backend, matching native stale-path cleanup and legacy `~/.misty/open_with.json` migration behavior.
- Settings now includes an Open With Associations panel backed by Tauri commands for listing valid mappings, pruning missing app paths, and removing remembered associations without editing raw JSON.
- Paste now checks system clipboard text when there is no active cut payload, copies newline-delimited existing paths as file refs, and stages arbitrary text as `clipboard.txt` through the same operation queue used for local and remote paste/upload work.
- Paste now reads standard `text/uri-list` clipboard data when the browser Clipboard API exposes it, converts `file://` URIs into local paths, validates them, and queues them as file-reference paste operations.
- Paste now asks a native macOS Tauri command for Finder/NSPasteboard file references before browser clipboard fallbacks, allowing copied Finder files to enter the same queued paste path.

- Paste now reads system clipboard images, converts RGBA clipboard pixels to PNG in the webview, stages the PNG through the Tauri backend, and queues it as `clipboard.png` for local or remote destinations.
- Transfers and operation-queue background polling now avoid visible working-state flips, use route-level selectors, compare queue snapshots field-by-field, and skip React state replacement when snapshots are unchanged, reducing idle repaint churn in the migrated transfer surface.
- Explorer and Transfers polling now avoid overlapping snapshot requests, and Explorer workspace persistence/context-menu listeners avoid unnecessary resubscription churn during normal pane interaction.
- App shell provider/transfer/settings notices are now isolated from the heavy route tree, and the top-level Explorer/Transfers/Providers/Settings workspaces are memoized to reduce background status updates cascading into multipanel renders.
- Explorer pane refreshes are now coalesced per pane/path, preventing bursts of transfer or file-operation completions from stacking redundant relist timers.
